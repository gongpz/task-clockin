║  任务打卡系统 · 宝塔 / AMH 面板网页安装说明                   ║
╚══════════════════════════════════════════════════════════════╝

要求：PHP 8.1 以上（推荐 8.2），扩展 pdo_mysql、mbstring（gd、curl、zip 建议装上）；
      MySQL 5.7 / 8.0 或 MariaDB 10.3 以上；Nginx 或 Apache。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 1 步  建网站
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  宝塔：网站 → 添加站点，填域名，PHP 版本选 8.2，数据库选「MySQL」顺手建一个
        （或者先选「不创建」，到第 2 步单独建）
  AMH ：虚拟主机 → 新增主机，填域名，选 PHP 8.x 环境

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 2 步  建数据库
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  宝塔：数据库 → 添加数据库，字符集 utf8mb4，记下 数据库名 / 用户名 / 密码
  AMH ：MySQL → 新增数据库 + 新增用户并授权该库，记下这三项

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 3 步  上传并解压
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  打开网站根目录（宝塔：文件 → /www/wwwroot/你的域名；AMH：/home/wwwroot/环境/domain/你的域名/web），
  删掉面板自动生成的 index.html，上传安装包 zip 并「解压」到当前目录。
  解压后根目录应能看到 index.php、app、install、storage 这几项（不要多套一层文件夹）。

  目录权限：网站根目录和 storage 要能被 PHP 写入。
  宝塔一般默认就是 www 用户；如安装页提示「不可写」，在 网站 → 设置 → 网站目录 里把所有者改成 www。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 4 步  设伪静态（Nginx 必做，Apache 自动生效可跳过）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  打开安装包里的「伪静态-直接粘贴.txt」，复制全部内容：
  宝塔：网站 → 设置 → 伪静态，粘贴后保存
  AMH ：虚拟主机 → 编辑 → Rewrite 规则，新建规则粘贴并选用
  这一步同时会挡住 .env、程序目录和上传目录里的脚本，必须做。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 5 步  打开安装向导
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  浏览器打开  http://你的域名/install/
  看环境检测都通过 → 填数据库信息、系统名称、管理员账号密码 → 开始安装。
  装完会自动锁定安装向导；为了安全，再到面板「文件」里把 install 目录删掉。

  后台：http://你的域名/admin/login      前台：http://你的域名/tasks

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  · 打开后台是 404：伪静态没设，回到第 4 步
  · 连不上数据库：核对库名 / 用户名 / 密码；AMH 用 socket 时「数据库地址」填 socket 路径
  · 页面提示已经安装过：根目录已有 .env 或 storage/install.lock。确实要重装，删掉这两个文件再打开
    /install/，勾选「沿用库里已有的数据」就不会动原来的数据
  · 以后升级：重新下载新版安装包，只覆盖 app、index.php、VERSION（不要覆盖 .env 和 storage），
    或者在服务器上用一键部署命令（见 GitHub 仓库 README）

  HTTPS：宝塔 网站 → 设置 → SSL 一键申请；AMH 用 amssl 模块申请。
