# Implementation Plan

## Requirement 1: User Personal Center + Binding

### Changes needed:

**1. New route: `/my` (GET) — Personal Center page**
- Shows user info (name, mobile, email)
- Quick links: 进入打卡 (→ /tasks), 查看打卡记录 (→ /my/records), 修改密码
- If user is NOT bound to a system member AND there's a same-name member in the system, show binding prompt with member's mobile/position/department
- If already bound, show bound member info

**2. New route: `/my/password` (GET/POST) — Change Password**
- Form: old password, new password, confirm password
- Validates old password, updates to new

**3. New route: `/my/bind` (POST) — Confirm Binding**
- User confirms binding to an existing system member
- Updates the existing member's `user_id` and `is_bound`

**4. New service functions in `services.php`:**
- `find_matching_members_by_name(string $name, int $userId)` — find system members with same name that aren't bound to another user
- `bind_user_to_member(int $userId, int $memberId)` — bind user to existing member
- `change_user_password(int $userId, string $oldPwd, string $newPwd)` — change password

**5. Modify login/register redirects:**
- After login: redirect to `/my` instead of `/tasks`
- After register: redirect to `/my` instead of `/tasks`

**6. Update layout header:**
- Change user name link from `/my/records` to `/my`

**7. New template: `user_center.php`**
- Personal center UI with binding prompt if applicable
